§ 02 · PROCESS

A four layer system that turns scattered virality into durable method.

Case, Creator, Lab, Skill. Each layer feeds the next so signal compounds over time.

01CASE

Discover viral cases

A crawler plus curator seed pulls AI videos and coding workflows from X, Bilibili, WeChat, Xiaohongshu, Reddit, and Discord while they are still actively spreading.

sources ─▶ index
02CREATOR

Community love signals

Signed-in readers like, save, follow, submit reproductions, and add parameters. Only real engagement counts; bots and self-inflation are filtered with provenance checks.

index ─▶ love rank
03LAB

Cross model validation

Top loved cases are re-run with the same normalized prompt across frontier models. Every run reports repro rate, consistency, visual drift, and cost per clip.

prompt ─▶ N models
04SKILL

Turn creator patterns into Skills

When a creator's cases repeatedly converge on the same pattern with measurable stability, that pattern is promoted into a reusable Skill — always attributed back to the creator.

pattern ─▶ skill ↗

§ 08 · METHODOLOGY / TRUST

How the signals work, and why they deserve trust.

Clear scoring, public lab logic, creator attribution, and visible updates keep the system credible.

01 / LOVE

Where Love Ranking comes from

Love is not a like count. It's a weighted aggregate of signed-in actions with cost attached: saving, following, submitting a reproduction, dropping parameters, and adding notes. Bot farms and self-inflation are filtered with provenance checks.

  • Save · 1.0×Signed-in only. Expires after 90 days unless re-engaged.
  • Follow · 1.4×Follow the creator, not the post. Costly to fake.
  • Repro attempt · 3.5×Most expensive action — you actually ran it.
  • Parameter / note · 2.2×You added knowledge for everyone.
02 / LAB

How the Stability Lab spends its budget

Top-loved cases are re-run on our dime with a normalized prompt across a rotating model matrix (N≥18). Every run reports repro rate, consistency, visual drift, and cost-per-output. Costs and failed runs are public.

  • Prompt hashEvery run references a signed, immutable prompt hash.
  • N ≥ 18 per caseEnough to call something stable without burning a month of API.
  • Failures publishedRepro failures aren't hidden; they lower the score publicly.
  • $ per outputDollars and API time are shown next to every score.
03 / SKILL

How creators become Skills

A creator's cases are clustered in an embedding space. When ≥4 cases sit inside the same cluster and survive the Lab with average repro ≥ 60%, the pattern is proposed as a Skill — always attributed to the creator, versioned like software.

  • ≥ 4 clustered casesPattern has to repeat, not just work once.
  • ≥ 60% average reproElse it's an art piece, not a method.
  • Creator attributionSkills carry the creator's name, forever.
04 / UPDATES

How scores update over time

Every score decays. Love decays over 30 days; Stability re-runs monthly or when a new frontier model drops. Nothing stays on the ranking forever just because it was great six months ago.

  • Love half-life · 30dYesterday's virality doesn't dominate today.
  • Lab refresh · 30dPlus immediate re-run on any frontier model release.
  • Open audit logEvery score change links to the run that caused it.
